# 관리자 목록 검색·로고 변경

> 개발 중 이관 기록입니다. Git 기준 신규 배포는 [DEV_RELEASE.md](DEV_RELEASE.md)를 따릅니다. `tools/*.py`는 일회성 로컬 패치 기록이며 릴리스에 포함하지 않습니다.


공식 로고 참고 원본은 `public/img/church-logo-original.png`, 투명 배경으로 정리한 표시용 파일은 `public/img/church-logo.png`입니다. 로그인 및 사이드바에 같은 로고를 사용합니다.

## 목록 기능

생방송·다시보기·접속 이력·블랙리스트·관리자·설교자·공지사항 목록에 10/20/50/100개씩 보기, 날짜 시작/종료, 검색어, 조회·초기화, 결과 건수를 제공합니다. 개수·검색 조건 변경은 1페이지부터 시작합니다. 기존 교회·설교자 필터도 유지합니다.

- 생방송·다시보기: 예배일, 제목/예배 종류/영상 링크(다시보기는 설교자 포함).
- 접속 이력: 입장일, 이름/구분 코드.
- 블랙리스트: 등록일, 닉네임.
- 관리자: 등록일, 이름/교회 코드. 비밀번호는 검색·목록 조회 대상에서 제외합니다.
- 설교자: 등록일, 이름.
- 공지사항: 공지 기간과 조회 기간이 겹치는 항목, 제목/본문.

종료일 당일 전체를 포함합니다. 날짜를 한쪽만 입력할 수도 있습니다. 조건은 AND, 검색어 대상 컬럼은 OR입니다. `%`, `_`는 일반 문자로 검색하고 SQL 값은 바인딩합니다. 잘못된 날짜·역순 기간은 거부하며 표시 개수는 허용된 네 값으로 제한합니다.

## 페이지 이동

5개 번호 묶음에서 다음은 다음 묶음 첫 페이지, 이전은 이전 묶음 마지막 페이지입니다. 예: 1~5 → 다음 6, 6~10 → 다음 11/이전 5. 첫·마지막 버튼은 전체 첫·마지막 페이지입니다. 마지막 묶음에서는 다음이 비활성화됩니다.

## dev 반영

`tools/upgrade_admin_lists.py` 한 파일에 코드 및 로고가 포함돼 있습니다. 별도 MVC dev 폴더만 허용하며 변경 전 백업, PHP 문법 검사, 권한·검색·페이지 이동·공지 회귀 검사, DB 읽기 전용 검색 검사를 실행합니다. 테스트를 통과한 경우에만 반영합니다. DB 레코드/스키마는 변경하지 않습니다.
