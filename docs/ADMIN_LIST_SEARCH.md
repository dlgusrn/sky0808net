# 관리자 목록 검색·로고 변경

공식 로고 참고 원본은 `public/img/church-logo-original.png`, 투명 배경으로 정리한 표시용 파일은 `public/img/church-logo.png`입니다. 로그인 및 사이드바에 같은 로고를 사용합니다.

## 목록 기능

모든 관리 목록에 10/20/50/100개씩 보기, 검색어, 조회·초기화, 결과 건수를 제공합니다. 기간 조회가 있는 목록에는 시작일자·종료일자도 표시합니다. 개수·검색 조건 변경은 1페이지부터 시작합니다. 기존 교회·설교자 필터도 유지합니다.

- 생방송·다시보기: 예배일, 제목/예배 종류/영상 링크(다시보기는 설교자 포함).
- 접속 이력: 입장일, 이름/구분 코드.
- 블랙리스트: 전체 기간, 닉네임. 최근 등록 순으로 표시합니다.
- 관리자: 전체 기간, 이름/교회 코드. 비밀번호는 검색·목록 조회 대상에서 제외합니다.
- 설교자: 전체 기간, 이름.
- 공지사항: 공지 기간과 조회 기간이 겹치는 항목, 제목/본문.

종료일 당일 전체를 포함합니다. 날짜를 한쪽만 입력할 수도 있습니다. 조건은 AND, 검색어 대상 컬럼은 OR입니다. `%`, `_`는 일반 문자로 검색하고 SQL 값은 바인딩합니다. 날짜 라벨은 시작일자·종료일자로 통일합니다. 날짜를 확정하면 자동 조회하고, 역순으로 변경하면 방금 바꾼 날짜에 맞춰 반대쪽도 조정합니다. 서버는 잘못된 날짜·역순 기간을 거부하며 표시 개수는 허용된 네 값으로 제한합니다.

## 페이지 이동

5개 번호 묶음에서 다음은 다음 묶음 첫 페이지, 이전은 이전 묶음 마지막 페이지입니다. 예: 1~5 → 다음 6, 6~10 → 다음 11/이전 5. 첫·마지막 버튼은 전체 첫·마지막 페이지입니다. 마지막 묶음에서는 다음이 비활성화됩니다.

## 기간 제한 없는 메뉴

블랙리스트·관리자·설교자 관리는 날짜/기간 조건 없이 전체 기간을 대상으로 검색어 조회합니다. 검색어가 없으면 전체 항목을 표시합니다. 표시 개수(10/20/50/100)와 페이지 이동은 유지합니다. 이전 URL에 날짜가 남아 있어도 서버에서 무시하고 페이지 링크에서도 제거하며 검색어는 유지합니다. 접속 이력은 오늘 조회가 기본이며 기간 선택에 오늘 옵션을 제공합니다. 생방송·다시보기·공지사항도 오늘 옵션을 제공하되 기본 1주일 조회를 유지합니다. 코드는 [Git 배포 절차](GIT_DEPLOYMENT.md)로 반영합니다.

## 방송 등록·상태 변경 안전장치

등록·수정·사용/송출 토글·삭제는 공통 MySQL 연결 잠금과 트랜잭션을 사용합니다. 새 등록 또는 사용 Y 전환 시 같은 교회의 다른 방송은 사용·송출 N으로 바꾸고, 선택한 방송도 송출 N에서 시작합니다. 사용 N 방송은 송출 Y로 켤 수 없습니다. 교회 이동 시 송출 상태를 N으로 초기화하며, 사용 Y 방송의 이동은 도착 교회의 기존 선택도 해제합니다. 같은 교회에서 제목 등 정보만 수정하면 현재 송출 상태를 유지합니다. 실패하면 관련 변경을 롤백합니다.

토글은 브라우저의 예상 상태와 현재 DB 상태가 다르면 거절하고 목록을 새로 읽습니다. 화면에 보이지 않는 과거 방송도 같은 교회라면 해제 대상에 포함됩니다. 다른 교회는 영향을 받지 않습니다.

관리자 등록·수정·삭제·토글·로그인·로그아웃은 POST와 CSRF 검사를 적용합니다. 화면의 폼·삭제 버튼·토글·로그아웃 버튼도 이에 맞춰 POST로 요청합니다. 일반 사용자 기본 비밀번호와 로그인 동작은 이번 수정에서 변경하지 않았습니다.

블랙리스트는 최근 등록 순으로 조회하며 번호도 검색 결과 총 건수에서 페이지 위치를 빼는 역순으로 표시합니다.

## 공통 목록 화면

검색 영역은 작은 입력으로 묶고, 날짜 조회는 오늘·1주일·1개월·3개월·1년·직접 선택 select를 사용합니다. 날짜가 없는 블랙리스트·관리자·설교자 목록에는 기간 조회를 표시하지 않습니다. 교회와 설교자 필터는 해당 목록의 검색 영역에 함께 배치합니다.

표 위 도구 모음의 왼쪽에는 검색 결과 총 건수와 등록하기를, 오른쪽에는 페이지네이션과 표시 개수를 순서대로 배치합니다. 선택 삭제가 있는 메뉴는 왼쪽 등록하기 옆에 유지하고, 접속 이력에는 등록 버튼이 없습니다. 표시 개수 select는 검색 폼과 연결되어 검색 조건을 유지하며 첫 페이지부터 조회합니다. 모바일에서는 도구 모음을 두 줄로 배치하고 표 내부 가로 스크롤을 유지합니다.
