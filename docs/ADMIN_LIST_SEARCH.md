# 관리자 목록 검색·로고 변경

공식 로고 참고 원본은 `public/img/church-logo-original.png`, 투명 배경으로 정리한 표시용 파일은 `public/img/church-logo.png`입니다. 로그인 및 사이드바에 같은 로고를 사용합니다.

## 목록 기능

모든 관리 목록에 10/20/50/100개씩 보기, 검색어, 조회·초기화, 결과 건수를 제공합니다. 기간 조회가 있는 목록에는 시작일자·종료일자도 표시합니다. 개수·검색 조건 변경은 1페이지부터 시작합니다. 기존 교회·설교자 필터도 유지합니다.

- 생방송·다시보기: 예배일, 제목/예배 종류/영상 링크(다시보기는 설교자 포함).
- 접속 이력: 입장일, 이름/구분 코드.
- 블랙리스트: 전체 기간, 닉네임. 최근 등록 순으로 표시합니다.
- 관리자: 전체 기간, 이름/교회 코드. 비밀번호는 검색·목록 조회 대상에서 제외합니다.
- 설교자: 전체 기간, 이름.
- 공지사항: 공지 기간과 조회 기간이 겹치는 항목, 제목/본문.

종료일 당일 전체를 포함합니다. 날짜를 한쪽만 입력할 수도 있습니다. 조건은 AND, 검색어 대상 컬럼은 OR입니다. `%`, `_`는 일반 문자로 검색하고 SQL 값은 바인딩합니다. 날짜 라벨은 시작일자·종료일자로 통일합니다. 날짜를 확정하면 자동 조회하고, 역순으로 변경하면 방금 바꾼 날짜에 맞춰 반대쪽도 조정합니다. 서버는 잘못된 날짜·역순 기간을 거부하며 표시 개수는 허용된 네 값으로 제한합니다.

## 페이지 이동

5개 번호 묶음에서 다음은 다음 묶음 첫 페이지, 이전은 이전 묶음 마지막 페이지입니다. 예: 1~5 → 다음 6, 6~10 → 다음 11/이전 5. 첫·마지막 버튼은 전체 첫·마지막 페이지입니다. 마지막 묶음에서는 다음이 비활성화됩니다.

## 기간 제한 없는 메뉴

블랙리스트·관리자·설교자 관리는 날짜/기간 조건 없이 전체 기간을 대상으로 검색어 조회합니다. 검색어가 없으면 전체 항목을 표시합니다. 표시 개수(10/20/50/100)와 페이지 이동은 유지합니다. 이전 URL에 날짜가 남아 있어도 서버에서 무시하고 페이지 링크에서도 제거하며 검색어는 유지합니다. 접속 이력은 당일 조회가 기본이며 당일 버튼을 제공합니다. 생방송·다시보기·공지사항은 기본 1주일 조회를 유지합니다. 코드는 [Git 배포 절차](GIT_DEPLOYMENT.md)로 반영합니다.
