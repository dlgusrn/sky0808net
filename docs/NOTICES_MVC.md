# 공지사항 MVC 이관

> 개발 중 이관 기록입니다. Git 기준 신규 배포는 [DEV_RELEASE.md](DEV_RELEASE.md)를 따릅니다. `tools/*.py`는 일회성 로컬 패치 기록이며 릴리스에 포함하지 않습니다.


관리자 `/admin/notice`에서 목록·페이지 이동·등록·수정·공지노출 토글을 제공합니다. 사용자 `/live/choice`는 활성화되어 있고 시작일~종료일에 해당하는 최신 공지 한 건을 표시합니다. 오늘 하루 숨기기는 기존처럼 24시간 쿠키로 유지합니다.

- 기존 `notice` 테이블과 데이터를 그대로 사용하며 DB 스키마 변경은 없습니다.
- 관리자 권한은 `live_manage`와 기존 `notice` 권한을 검사합니다. DB에 `notice` 권한 컬럼이 없는 환경만 `live_list` 권한으로 대체합니다. 기존 권한 컬럼이 있으면 관리자 등록·수정에도 체크 항목이 표시됩니다.
- 등록·수정·토글은 POST/CSRF 검증을 거칩니다. 제목·내용은 적절히 이스케이프 또는 HTML 허용 목록으로 처리합니다. 기본 서식·링크·이미지·표를 지원하며 스크립트와 이벤트 속성은 제거합니다.
- 첨부는 실제 MIME 및 이미지 판별을 통과한 JPG/PNG/GIF, 최대 5MB만 허용합니다. PHP/Apache 업로드 한도가 더 낮으면 서버 설정 조정이 필요합니다.
- 첨부는 공개 루트 밖 `storage/notice`에 저장하고 `/live/notice_attachment`에서 로그인 확인 후 제공합니다. 기존 본문의 `/live/uploads/이미지`도 이 경로로 연결합니다.
- 새 첨부 없이 수정하면 기존 첨부를 보존합니다. 교체한 옛 파일도 삭제하지 않습니다. 원래 기능에 없던 공지 삭제 기능은 추가하지 않았습니다.

## dev 적용

Mac에서 `tools/migrate_notices.py`만 서버에 복사한 뒤:

```sh
python3 /root/migrate_notices.py \
  /var/www/html/sky0808net-mvc-dev \
  /var/www/html/sky0808net/live/uploads
```

이 스크립트는 MVC dev 폴더만 허용합니다. 스키마·DOM/fileinfo 확장, 변경 파일의 PHP 문법, 공지 단위 테스트와 전체 관리자 권한 테스트를 임시 폴더에서 먼저 검사합니다. 실패하면 애플리케이션 파일을 반영하지 않습니다. 통과하면 원본 업로드는 건드리지 않고 이미지 복사본을 준비하고, 코드를 `.migration-backups/notices-시간/`에 백업한 뒤 적용합니다. DB 레코드는 배포 중 변경하지 않습니다.

적용 후 기존 공지/첨부 열람, 새 공지 등록, 편집기 본문 수정, 첨부 미교체 유지 및 교체, 기간/노출 토글, 사용자 팝업·숨김, 권한 없는 요청 거부를 확인합니다. 테스트 공지는 확인 후 노출 N으로 되돌립니다.
